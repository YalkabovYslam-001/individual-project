# Итоги недели

На этой неделе была начата реализация индивидуального проекта — персонального сайта студента.

Основной задачей стало создание рабочего сайта, его настройка и публикация в интернете с использованием современных инструментов веб-разработки.

## Что было сделано

В течение недели были выполнены следующие задачи:

- установка Hugo;
- установка необходимых инструментов;
- скачивание и настройка шаблона Hugo Academic / HugoBlox;
- создание GitHub-репозитория;
- настройка Git;
- настройка параметра `baseURL`;
- настройка GitHub Actions;
- публикация сайта через GitHub Pages;
- настройка персонального профиля;
- добавление фотографии;
- добавление биографии;
- добавление интересов;
- добавление информации об образовании;
- разработка структуры главной страницы;
- настройка навигации сайта.

## Настройка Hugo

Для создания сайта был выбран генератор статических сайтов Hugo.

Hugo позволяет создавать быстрые статические сайты с использованием Markdown, шаблонов и конфигурационных файлов.

В процессе работы был установлен Hugo и проверена его работоспособность.

Для запуска локального сервера используется команда:

```bash
hugo server
