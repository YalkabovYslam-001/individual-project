# Итоги недели

На этой неделе продолжилась работа над индивидуальным проектом — разработкой и наполнением персонального сайта.

## Что было сделано

В течение недели были выполнены следующие задачи:

- продолжена настройка персонального сайта;
- настроен профиль автора;
- добавлена персональная информация;
- добавлена фотография;
- добавлена информация об образовании;
- добавлена информация об интересах;
- добавлена информация о навыках;
- добавлена информация об опыте;
- добавлена информация о достижениях;
- настроена навигация сайта;
- добавлены учебные и персональные проекты;
- добавлен проект по Linux и Bash;
- добавлены ссылки на научные и библиометрические ресурсы;
- настроены ссылки на Google Scholar;
- настроена ссылка на ORCID;
- добавлена ссылка на GitHub;
- добавлена ссылка на ResearchGate;
- добавлена ссылка на Academia.edu;
- продолжена работа с Git и GitHub;
- проверена сборка сайта с помощью Hugo;
- продолжена настройка автоматической публикации сайта через GitHub Pages.

## Научные и библиометрические ресурсы

Для профессионального представления информации были добавлены ссылки на научные и библиометрические профили.

На сайте размещены ссылки на:

- Google Scholar;
- ORCID;
- ResearchGate;
- Academia.edu;
- GitHub;
- eLibrary.

## Работа над проектами

В разделе проектов были представлены следующие работы:

- интерактивный веб-проект «Химический гид»;
- проект по работе с Git и GitHub;
- индивидуальный проект — персональный сайт;
- учебный проект по Linux и Bash.

Для каждого проекта была создана отдельная страница с описанием, используемыми технологиями и целью работы.

## Полученные навыки

В процессе работы были закреплены практические навыки:

- создания сайтов с использованием Hugo;
- работы с HugoBlox;
- написания документов в Markdown;
- работы с Git;
- работы с GitHub;
- настройки GitHub Pages;
- использования GitHub Actions;
- работы с HTML и CSS;
- организации структуры статического сайта;
- публикации веб-сайта в интернете.

## Результат

В результате сайт был значительно расширен и наполнен персональной и учебной информацией.

На сайте теперь представлены профиль автора, образование, навыки, опыт, достижения, проекты, публикации и ссылки на научные и профессиональные ресурсы.

## Следующий этап

В дальнейшем планируется продолжить развитие сайта, улучшать его содержание и оформление, а также добавлять новые материалы и проекты.
