# Непрерывная интеграция и непрерывное развертывание

## Что такое CI/CD

CI/CD — это подход к автоматизации разработки программного обеспечения.

CI означает Continuous Integration — непрерывную интеграцию.

CD означает Continuous Delivery или Continuous Deployment — непрерывную доставку или непрерывное развёртывание программного продукта.

Использование CI/CD позволяет автоматически выполнять проверку, сборку и публикацию проекта после внесения изменений.

## GitHub Actions

В индивидуальном проекте для автоматизации используется GitHub Actions.

После отправки изменений в репозиторий GitHub запускается workflow.

Workflow выполняет несколько операций:

1. получает исходный код проекта;
2. устанавливает Hugo;
3. устанавливает Node.js и зависимости;
4. выполняет сборку сайта;
5. создаёт готовые файлы сайта;
6. загружает результат;
7. публикует сайт через GitHub Pages.
