# Индивидуальный проект — персональный сайт

Персональный сайт студента, разработанный в рамках индивидуального проекта.

## Используемые технологии

- Hugo;
- HugoBlox;
- Markdown;
- HTML;
- CSS;
- Git;
- GitHub;
- GitHub Actions;
- GitHub Pages.

## Что реализовано

На сайте размещены:

- информация обо мне;
- фотография;
- образование;
- интересы;
- навыки;
- опыт;
- достижения;
- учебные проекты;
- публикации;
- ссылки на профессиональные и научные ресурсы.

## Цель проекта

Цель проекта — разработать современный персональный сайт и разместить его в интернете с использованием GitHub Pages.

Проект также позволяет получить практический опыт работы с генератором статических сайтов, Git, GitHub и CI/CD.
