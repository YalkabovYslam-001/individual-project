# Git и GitHub

Учебный проект по использованию системы контроля версий Git и платформы GitHub.

## Используемые технологии

- Git;
- GitHub;
- GitHub Actions;
- GitHub Pages;
- Git branches;
- GitHub repository.

## Что изучено

В процессе работы были изучены:

- создание репозитория;
- коммиты;
- ветки;
- отправка изменений на GitHub;
- синхронизация локального и удалённого репозитория;
- GitHub Actions;
- автоматическая публикация сайта.

## Цель

Получить практические навыки работы с системой контроля версий и современными инструментами CI/CD.
