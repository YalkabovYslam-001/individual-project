# Химический гид

Интерактивный веб-проект, посвящённый химическим элементам и таблице Менделеева.

## Возможности

Проект включает:

- интерактивную таблицу химических элементов;
- информацию об элементах;
- визуальное оформление элементов;
- тестирование знаний;
- интерактивные элементы интерфейса.

## Используемые технологии

- HTML;
- CSS;
- JavaScript;
- Bootstrap.

## Цель

Цель проекта — получить практические навыки создания интерактивных веб-приложений и работы с HTML, CSS и JavaScript.
