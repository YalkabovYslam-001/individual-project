# Markdown Markup Language

Markdown is a lightweight markup language designed for easily creating structured text documents.

It is widely used in programming, web development, documentation, and version control systems.

## Main Features

Markdown allows you to create:

- headings;
- lists;
- tables;
- links;
- images;
- text formatting;
- code blocks;
- quotations.

For example, a heading is created using the `#` symbol:

```text
# Heading
