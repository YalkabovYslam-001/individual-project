# Chemical Guide

An interactive web project dedicated to chemical elements and the periodic table.

## Features

The project includes:

- an interactive periodic table of chemical elements;
- information about the elements;
- visual styling of the elements;
- a knowledge quiz;
- interactive interface elements.

## Technologies Used

- HTML;
- CSS;
- JavaScript;
- Bootstrap.

## Goal

The goal of the project is to gain practical skills in creating interactive web applications and working with HTML, CSS, and JavaScript.
