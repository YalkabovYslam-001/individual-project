# Linux and Bash

An academic project combining practical laboratory work on the Linux operating system and the command line.

## Technologies Studied

The following technologies and concepts were studied as part of the project:

- Linux;
- Fedora;
- Bash;
- PowerShell;
- Linux file system;
- access permissions;
- processes;
- variables;
- conditions;
- loops;
- shell scripts.

## Practical Work

During the laboratory work, files and directories were managed, Linux commands were studied, Bash scripts were created, and various command-line interpreter constructs were practiced.

The following topics were covered:

- working with files and directories;
- file searching;
- input and output redirection;
- variables;
- command-line arguments;
- conditional statements;
- loops;
- creating shell scripts;
- task automation.

## Project Goal

The goal of the project is to gain practical skills in working with the Linux operating system, the Bash command line, and basic automation tools.

## Result

As a result of completing the laboratory work, practical Linux skills were acquired along with an understanding of the basic principles of programming in a command-line interpreter.
