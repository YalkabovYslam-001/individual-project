# Individual Project — Personal Website

A personal student website developed as part of an individual project.

## Technologies Used

- Hugo;
- HugoBlox;
- Markdown;
- HTML;
- CSS;
- Git;
- GitHub;
- GitHub Actions;
- GitHub Pages.

## Implemented Features

The website includes:

- information about me;
- profile photo;
- education;
- interests;
- skills;
- experience;
- achievements;
- academic projects;
- publications;
- links to professional and academic resources.

## Project Goal

The goal of the project is to develop a modern personal website and publish it online using GitHub Pages.

The project also provides practical experience with a static site generator, Git, GitHub, and CI/CD.
