# Linux и Bash

Учебный проект, объединяющий практические лабораторные работы по операционной системе Linux и командной строке.

## Изученные технологии

В рамках проекта были изучены:

- Linux;
- Fedora;
- Bash;
- PowerShell;
- файловая система Linux;
- права доступа;
- процессы;
- переменные;
- условия;
- циклы;
- командные файлы.

## Практическая часть

В ходе лабораторных работ выполнялась работа с файлами и каталогами, изучались команды Linux, создавались Bash-скрипты и отрабатывались различные конструкции командного интерпретатора.

Были рассмотрены:

- работа с файлами и каталогами;
- поиск файлов;
- перенаправление ввода и вывода;
- переменные;
- аргументы командной строки;
- условные конструкции;
- циклы;
- создание командных файлов;
- автоматизация выполнения задач.

## Цель проекта

Цель проекта — получить практические навыки работы с операционной системой Linux, командной строкой Bash и основными инструментами автоматизации.

## Результат

В результате выполнения лабораторных работ были получены практические навыки работы в Linux и понимание принципов программирования в командном интерпретаторе.
