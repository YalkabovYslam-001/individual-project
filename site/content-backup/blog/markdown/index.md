# Язык разметки Markdown

Markdown — это лёгкий язык разметки, предназначенный для удобного создания структурированных текстовых документов.

Он широко используется в программировании, веб-разработке, документации и системах контроля версий.

## Основные возможности

Markdown позволяет создавать:

- заголовки;
- списки;
- таблицы;
- ссылки;
- изображения;
- выделение текста;
- блоки кода;
- цитаты.

Например, заголовок создаётся с помощью символа `#`:

```text
# Заголовок
