# Итоги недели

На этой неделе продолжилась работа над индивидуальным проектом — созданием персонального сайта.

## Что было сделано

В течение недели были выполнены следующие задачи:

- установлен и настроен Hugo;
- установлен и настроен необходимый набор инструментов для разработки;
- изучена структура HugoBlox;
- настроен персональный профиль;
- добавлена фотография;
- добавлена информация обо мне;
- добавлена информация об образовании;
- добавлена информация об интересах;
- настроена навигация сайта;
- создан GitHub-репозиторий;
- настроен Git;
- настроирована автоматическая публикация сайта;
- настроен GitHub Pages;
- проверена работа сайта в интернете.

## Результат

В результате был создан рабочий персональный сайт, содержащий информацию обо мне, моём образовании, интересах и проектах.

Сайт размещён на GitHub Pages, поэтому после внесения изменений и отправки их в репозиторий сайт может автоматически обновляться.

## Что изучено

В процессе работы были получены практические навыки работы с:

- Hugo;
- HugoBlox;
- Markdown;
- Git;
- GitHub;
- GitHub Actions;
- GitHub Pages;
- HTML и CSS;
- PowerShell;
- Visual Studio Code.

## Следующий этап

В дальнейшем планируется продолжить развитие персонального сайта, расширить информацию о навыках, опыте и достижениях, а также поддерживать актуальность научных и библиометрических профилей.
