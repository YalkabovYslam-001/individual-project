# eLibrary

**eLibrary** — российская научная электронная библиотека.

Используется для:

* поиска научных статей;
* поиска авторов;
* поиска журналов;
* работы с научной литературой;
* анализа публикационной активности.

Ссылка на ресурс добавлена в научный раздел сайта.

---

# Google Scholar

**Google Scholar** используется для поиска научной литературы.

С его помощью можно находить:

* научные статьи;
* книги;
* диссертации;
* материалы конференций;
* публикации научных издательств.

Также сервис позволяет создавать профиль исследователя.

---

# ORCID

**ORCID** предоставляет уникальный идентификатор исследователя.

Основные возможности:

* идентификация автора;
* связь автора с публикациями;
* использование единого идентификатора;
* интеграция с научными системами.

Ссылка на ORCID добавлена в профиль сайта.

---

# Mendeley

**Mendeley** предназначен для работы с научными публикациями и библиографией.

Используется для:

* хранения научных статей;
* организации библиотеки;
* работы с библиографическими данными;
* подготовки списка литературы;
* систематизации источников.

---

# ResearchGate и Academia.edu

### ResearchGate

Научная платформа для исследователей.

Позволяет:

* создавать профиль;
* размещать информацию о публикациях;
* находить исследователей;
* обмениваться научными материалами.

### Academia.edu

Платформа для размещения и распространения научных материалов.

---

# arXiv

**arXiv** — открытый архив научных материалов.

Особенно полезен для направлений:

* информатика;
* компьютерные науки;
* математика;
* физика;
* статистика.

Ресурс представляет интерес для изучения современных исследований в области IT.

---

# GitHub

GitHub используется как технический и профессиональный ресурс.

На GitHub размещаются:

* исходный код сайта;
* учебные проекты;
* история изменений;
* Markdown-файлы;
* конфигурация Hugo.

GitHub также используется для публикации сайта через GitHub Pages.

# Markdown для научных документов

Markdown позволяет создавать структурированные документы.

Пример:

```markdown
# Введение

## Актуальность

Описание актуальности исследования.

## Цель работы

Формулировка цели.

## Результаты

Полученные результаты.
```

Markdown удобен благодаря простому текстовому синтаксису.
