# Основы Markdown

Пример заголовков:

```markdown
# Заголовок
## Подзаголовок
### Раздел
```

Жирный текст:

```markdown
**жирный текст**
```

Курсив:

```markdown
*курсив*
```

Список:

```markdown
- первый пункт
- второй пункт
- третий пункт
```

# Markdown и LaTeX

Markdown может использоваться совместно с LaTeX.

Например:

```text
$$
E = mc^2
$$
```

LaTeX используется для:

* математических формул;
* научных документов;
* отчётов;
* статей;
* библиографии.
