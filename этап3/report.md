# 9. Структура еженедельного поста

Для публикации используется Markdown.

Пример начальной части файла:

```markdown
---
title: "Weekly Summary: Personal Website Development"
summary: "Results of the individual project work during the third week."
date: 2026-09-04
authors:
  - me
tags:
  - Hugo
  - Git
  - Markdown
---

## Introduction

During the third stage of the individual project,
the personal website was expanded with new
professional information.
```

Такой формат позволяет Hugo автоматически определить основные параметры страницы.

Основное внимание уделено **Markdown**.

---

# 11. Основные возможности Markdown

В тематической публикации рассмотрены основные элементы Markdown.

### Заголовки

```markdown
# Заголовок первого уровня
## Заголовок второго уровня
### Заголовок третьего уровня
```

### Жирный текст

```markdown
**жирный текст**
```

### Курсив

```markdown
*курсив*
```

### Список

```markdown
- первый пункт
- второй пункт
- третий пункт
```

---


# 12. Таблицы в Markdown

Markdown поддерживает создание таблиц.

Пример:

```markdown
| Технология | Назначение |
|---|---|
| Hugo | Создание сайта |
| Git | Контроль версий |
| Markdown | Форматирование текста |
```

После обработки Markdown таблица отображается в виде обычной структурированной таблицы.

---

# 13. Markdown и LaTeX

Markdown может использоваться вместе с LaTeX.

Например, математическая формула может быть записана следующим образом:

```text
$$
E = mc^2
$$
```

LaTeX предоставляет широкие возможности для оформления:

* математических формул;
* научных документов;
* отчётов;
* статей;
* библиографий.

Markdown при этом остаётся удобным инструментом для создания простых структурированных документов.
