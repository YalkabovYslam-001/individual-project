# 1. Цель работы

Целью первого этапа индивидуального проекта является создание и первоначальное размещение персонального веб-сайта на платформе **GitHub Pages**.

В рамках этапа необходимо:

* установить необходимое программное обеспечение;
* скачать и подготовить шаблон персонального сайта;
* создать репозиторий на GitHub;
* разместить исходные файлы сайта в репозитории;
* настроить параметр URL сайта;
* выполнить сборку сайта;
* опубликовать готовый сайт с использованием GitHub Pages;
* проверить доступность опубликованного сайта.

# 7. Локальный запуск сайта

Перед публикацией сайта необходимо было проверить его работу локально.

Для запуска локального сервера Hugo использовалась команда:

```powershell
hugo server
```

При необходимости для более стабильного обновления страниц можно использовать:

```powershell
hugo server --disableFastRender
```

После успешного запуска Hugo сообщает адрес локального сервера.

Обычно сайт становится доступен по адресу:

```text
http://localhost:1313/
```

Открытие данного адреса в браузере позволяет проверить внешний вид сайта до его публикации.

# 11. Настройка URL сайта

Для корректной работы сайта на GitHub Pages необходимо настроить базовый URL.

В конфигурационном файле Hugo указывается адрес будущего опубликованного сайта.

Пример:

```yaml
baseURL: "https://YalkabovYslam-001.github.io/..."
```

Конкретное значение `baseURL` зависит от названия GitHub-репозитория.

Параметр `baseURL` необходим Hugo для корректного формирования абсолютных ссылок на:

* страницы;
* изображения;
* CSS-файлы;
* JavaScript;
* другие ресурсы сайта.

# 13. Публикация сайта на GitHub Pages

Для публикации сайта была использована возможность **GitHub Pages**.

GitHub Pages позволяет размещать статические веб-сайты непосредственно из репозитория GitHub.

В настройках репозитория необходимо перейти в раздел:

```text
Settings → Pages
```

После этого выбирается источник публикации сайта.

В зависимости от используемой структуры проекта публикация может выполняться через:

* GitHub Actions;
* отдельную ветку;
* каталог с готовыми статическими файлами.

После выполнения процесса публикации GitHub Pages предоставляет URL опубликованного сайта.
