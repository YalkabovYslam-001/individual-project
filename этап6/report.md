# 1. Введение

На заключительном этапе индивидуального проекта была выполнена настройка многоязычной версии персонального сайта.

Основной задачей данного этапа стало создание поддержки двух языков:

* русского;
* английского.

Для реализации двуязычного сайта использовались возможности статического генератора Hugo.

В результате пользователь получил возможность выбирать язык интерфейса и просматривать страницы и публикации на русском или английском языке.

---

# 2. Цель и задачи работы

## Цель работы

Создать и разместить двуязычную версию персонального сайта на GitHub Pages.

## Задачи

В рамках шестого этапа необходимо было:

1. настроить поддержку русского языка;
2. настроить поддержку английского языка;
3. перевести основные элементы сайта;
4. разместить персональную информацию на обоих языках;
5. создать двуязычные версии страниц;
6. перевести публикации;
7. создать еженедельный пост;
8. создать тематическую публикацию на русском и английском языках;
9. проверить переключение между языками;
10. сохранить изменения в Git;
11. разместить обновлённую версию сайта на GitHub.

# 4. Создание двуязычного сайта

Hugo предоставляет встроенную поддержку многоязычных сайтов.

Для создания двуязычного сайта была настроена поддержка двух языков:

```text
Русский — ru
Английский — en
```

Для каждого языка создаётся отдельная версия содержимого сайта.

Общая схема работы:

```text
Персональный сайт
│
├── Русский язык
│   ├── Главная страница
│   ├── Обо мне
│   ├── Проекты
│   └── Публикации
│
└── English
    ├── Home
    ├── About
    ├── Projects
    └── Blog
```

# 5. Настройка русского языка

Русский язык был настроен как одна из языковых версий сайта.

Для него определяются:

* код языка;
* название языка;
* порядок отображения;
* направление текста;
* язык по умолчанию или дополнительный язык.

Пример настройки:

```yaml
languages:
  ru:
    languageCode: ru
    languageName: Русский
    weight: 1
```

После настройки Hugo может создавать русскую версию сайта.

---

# 6. Настройка английского языка

Для английской версии сайта были определены отдельные языковые параметры.

Пример:

```yaml

  en:

    weight: 2
```

Английская версия содержит переведённые:

* персональную информацию;
* описания;
* публикации;

Использование отдельных файлов позволяет разместить одинаковую информацию на разных языках.

# 11. Перевод публикаций

Для публикаций были созданы русская и английская версии.

Пример структуры одного материала:

```text
article/
├── index.ru.md
└── index.en.md
```

Для связи переводов между собой используется общий ключ.

Например:

```yaml
translationKey: week-6
```

Одинаковый ключ позволяет Hugo определить, что страницы являются переводами одного материала.

После настройки многоязычности сайт был проверен локально.

Для запуска использовалась команда:

```powershell

```

После запуска проверялись:

* русская версия сайта;
* английская версия сайта;
* переключатель языков;
* главная страница;
* страница «Обо мне»;
* раздел проектов;
* публикации;
* ссылки между языковыми версиями.

Особое внимание уделялось корректности перехода между русской и английской версиями одного и того же материала.
